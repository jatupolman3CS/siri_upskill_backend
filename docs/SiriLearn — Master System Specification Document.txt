SiriLearn — Master System Specification Document

Project Name: SiriLearn — Next-Generation Enterprise E-Learning Platform
Reference Models: SkillLane (Premium & Corporate) + FutureSkill (Modern Tech & Subscription)
Target Stack: Angular v22, .NET 10 Web API, Redis, Bunny Stream (DRM)

PART 1: Software Requirements Specification (SRS)

1. System Overview (ภาพรวมของระบบ)

SiriLearn เป็นแพลตฟอร์มการเรียนรู้ออนไลน์ระดับ Enterprise ที่รองรับโมเดลธุรกิจทั้งแบบ B2C (รายบุคคล) และ B2B (องค์กร) โดยมีจุดเด่นด้านระบบความปลอดภัยของวิดีโอระดับสูงสุด (DRM & Dynamic Watermark) และโมเดลการขายทั้งแบบ A La Carte (ซื้อขาดรายคอร์ส) และ Subscription (บุฟเฟต์สมาชิก)

2. User Roles (บทบาทผู้ใช้งาน)

Learner (ผู้เรียนทั่วไป): ผู้ใช้งานที่ซื้อคอร์สหรือสมัครสมาชิกแบบ Subscription

Corporate Learner (ผู้เรียนองค์กร): พนักงานที่ได้รับสิทธิ์เข้าเรียนจากบริษัท

Instructor (ผู้สอน/สถาบัน): ผู้สร้างเนื้อหา, อัปโหลดวิดีโอ, ดูสถิติ และรับส่วนแบ่งรายได้

HR Admin (ผู้ดูแลระบบองค์กร B2B): ตัวแทนบริษัทที่จัดการสิทธิ์ มอบหมายคอร์สเรียน และดูรายงาน

Superadmin (ผู้ดูแลระบบสูงสุด): เจ้าของแพลตฟอร์ม ดูแลภาพรวม การอนุมัติคอร์ส โปรโมชัน และการเงิน

3. Functional Requirements (ความต้องการทางฟังก์ชัน)

3.1 Learner Module (ระบบสำหรับผู้เรียน)

Authentication & Profile: สมัครสมาชิกผ่าน Email, Google, Facebook, Apple ID พร้อมระบบป้องกันการล็อกอินซ้อน (Concurrent Session Limit) สูงสุด 2 อุปกรณ์

Course Discovery & Learning Path:

Smart Search กรองตาม หมวดหมู่, ระดับ, ผู้สอน, และราคา

Learning Path / Bootcamp จัดกลุ่มคอร์สเรียนต่อเนื่องเพื่อเป้าหมายอาชีพ

Interactive Learning & Video Player:

วิดีโอสตรีมมิ่งผ่าน Bunny Stream HLS

Timestamp Notes: ฟีเจอร์จดโน้ตผูกกับเวลาวิดีโอ และปรับความเร็วการเล่น (0.5x - 2.0x)

Interactive Quiz ท้ายบท และระบบส่งการบ้าน

Gamification & Certification:

ระบบสะสมแต้ม (XP), Leaderboard และการออกใบประกาศนียบัตร (Digital Certificate) อัตโนมัติเมื่อเรียนจบ 100% พร้อม QR Code Verify

Payment & Subscription: รองรับ PromptPay QR, Credit Card, ระบบผ่อนชำระ และ Subscription (รายเดือน/รายปี)

3.2 Instructor Studio (ระบบสำหรับผู้สอน)

Course Builder (Drag & Drop): เครื่องมือจัดโครงสร้างหลักสูตร (Syllabus) จัดการ Episode, ตั้งค่า Free Preview และอัปโหลดไฟล์ประกอบ (PDF, Code)

Analytics Dashboard:

Drop-off Analytics: กราฟแสดงพฤติกรรมการหยุดดูวิดีโอของผู้เรียน เพื่อปรับปรุงเนื้อหา

รายงานยอดขาย ส่วนแบ่งรายได้ และเรตติ้ง

Student Engagement: กระดานถาม-ตอบ (Q&A) และระบบ Broadcast Announcement

3.3 Superadmin Console (ระบบหลังบ้านส่วนกลาง)

CMS & Marketing: จัดการ Hero Banner, เขียน Blog (SEO), สร้าง Promo Code, Flash Sale และ Course Bundling

Financial & Payout: ระบบคำนวณส่วนแบ่งรายได้อัตโนมัติ (เช่น 70/30 Split) และจัดการรอบบิลการโอนเงิน

Moderation: อนุมัติคอร์สก่อน Public, จัดการข้อพิพาท และระงับผู้ใช้งาน (Ban/Reset)

3.4 Corporate Dashboard (B2B HR Portal)

User & Course Management: อิมพอร์ตรายชื่อพนักงานด้วย Excel และบังคับพนักงานกลุ่มที่กำหนดให้เรียนคอร์สเฉพาะ (Mandatory Training)

Progress Reporting: แดชบอร์ดความคืบหน้าของพนักงาน สามารถ Export เป็น Excel/PDF

1.1 Core Capabilities (ระบบนี้ทำอะไรได้บ้าง?)

เพื่อความเข้าใจที่ชัดเจน ระบบ SiriLearn ประกอบด้วยฟังก์ชันหลักที่ทรงพลังดังต่อไปนี้:

🛒 1. ระบบร้านค้าและสมาชิก (Store & Subscription):

ขายคอร์สเรียนแบบรายวิชา (A La Carte) และแบบเหมาจ่ายรายเดือน/ปี (Subscription Buffet)

ระบบตะกร้าสินค้า, โปรโมชันโค้ด (Promo Code), และจัดเซ็ตคอร์ส (Course Bundle)

ชำระเงินผ่าน PromptPay QR (อัตโนมัติ), บัตรเครดิต และผ่อนชำระ

🛡️ 2. ระบบความปลอดภัยวิดีโอ (Anti-Piracy & DRM):

บล็อกการดาวน์โหลดวิดีโอด้วย IDM/Video Grabber (DRM Encryption)

มีลายน้ำ (Watermark) เป็นอีเมลผู้เรียน ลอยสุ่มไปมาบนวิดีโอเพื่อป้องกันการอัดหน้าจอ

เตะอุปกรณ์ที่ล็อกอินซ้อนทันที หากล็อกอินเกินกำหนด (Active Session Lock)

🎓 3. ห้องเรียนอัจฉริยะ (Interactive Classroom):

เล่นวิดีโอพร้อมปรับความเร็ว (0.5x - 2.0x) และจำเวลาที่เรียนค้างไว้ (Auto-Resume)

ระบบจดโน้ตผูกกับเวลาวิดีโอ (Timestamp Notes) และดาวน์โหลดเอกสารประกอบ

แบบทดสอบท้ายบท (Quiz) และระบบส่งการบ้าน (Assignment) ให้ผู้สอนตรวจ

กระดานถาม-ตอบ (Q&A) ประจำบทเรียน

🏆 4. ระบบประเมินผลและประกาศนียบัตร (Assessment & Certification):

วัดความคืบหน้า (Progress Tracking) เป็นเปอร์เซ็นต์

ระบบสร้างใบประกาศนียบัตร (e-Certificate) เป็น PDF อัตโนมัติเมื่อเรียนจบ 100% พร้อม QR Code ให้สแกนตรวจสอบความถูกต้อง (Verify)

🏢 5. ระบบองค์กร (B2B Corporate Portal):

HR นำเข้ารายชื่อพนักงาน จัดกลุ่ม และกำหนดคอร์สบังคับเรียน (Mandatory Training)

HR Dashboard ดูรายงานความคืบหน้าของพนักงานรายคน/รายแผนก และ Export เป็น Excel

🎙️ 6. สตูดิโอผู้สอน (Instructor Studio):

สร้างหลักสูตรด้วยการลากวาง (Drag & Drop Builder) กำหนดบทเรียนฟรี (Free Preview)

หน้าจอวิเคราะห์สถิติผู้เรียน เช่น "วิดีโอนี้นักเรียนมักจะกดปิดตอนกี่นาที" (Drop-off Analytics)

💰 7. ระบบจัดการหลังบ้านและการเงิน (Superadmin & Finance):

คำนวณส่วนแบ่งรายได้อัตโนมัติ (เช่น แพลตฟอร์ม 30% / ผู้สอน 70%) และหน้าจอสรุปยอดโอนเงิน

ระบบจัดการแบนเนอร์หน้าเว็บ (CMS) และแบนผู้ใช้งาน
